## About the Project

Midas is the project repository for the **J.P. Morgan Chase & Co. Advanced Software Engineering** virtual experience program hosted on [Forage](https://www.theforage.com/). The program simulates real-world tasks performed by software engineers at JPMC, focusing on financial data feeds, interface development, and live graph visualization using internal open-source tooling.

---

## Tasks

The program consists of the following tasks:

**Task 1 — Interface with a stock price data feed**
Set up a local development environment, fix broken Python scripts, and output correctly formatted data from a live stock price feed.

**Task 2 — Use JPMorgan Chase frameworks and tools**
Implement changes to a web application so that it displays data from the feed in a format traders can monitor — using React and JPMC's internal tooling.

**Task 3 — Display data visually for traders**
Use Perspective, J.P. Morgan's open-source data visualization tool, to generate a live graph that continuously updates as new data streams in from the feed.
